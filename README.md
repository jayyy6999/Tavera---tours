## 📋 How the Booking System Works

1. **Customer fills the booking form** with:
   - Name, Email, Phone
   - Destination (Goa, Kerala, Coorg, Ooty, Mysore, Hampi, Wayanad, Kodaikanal)
   - Tour Type (Adventure, Beach, Cultural, Nature, Food & Spice, Road Trips)
   - Vehicle Type (4 Seater, 6 Seater, 7 Seater, Urbania)
   - Preferred Date
   - Number of Members
   - Any additional message

2. **Clicks "Confirm & Send to WhatsApp"**

3. **Message is automatically formatted** with all details

4. **Opens WhatsApp** with the pre-filled message

5. **Customer can review and send** the booking request

6. **You receive it on WhatsApp** (9611053999) where you can:
   - Discuss pricing based on vehicle type
   - Confirm dates and availability
   - Send package details
   - Finalize the booking

## 🎨 Customization

### Add Gallery Images
1. Replace the placeholder gallery items in `index.html`
2. Add `<img>` tags with your photo URLs
3. Example:
```html
<div class="gallery-item">
    <img src="your-image-url.jpg" alt="Tour Image">
</div>
```

### Change Colors
- Update gradient colors in `style.css`
- Current: Purple/Blue gradient (`#667eea` to `#764ba2`)
- Change WhatsApp number: Update `919611053999` in `script.js`
